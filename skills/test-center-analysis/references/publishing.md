# 最后发布：交给 HTML Gallery

本技能不自行写上传接口或携带登录配置。读取并使用本机已安装的 `html-gallery` 技能；如不存在，先解释此可选依赖并按用户授权安装，由用户本人完成飞书授权。不要从仓库、截图、旧任务或其他人的机器取 token。

## 发布前必问

只有用户本次要求发布/更新时，完成内容与本地校验后再问：

> 当前报告是给客户看，还是给同事看？给同事看默认公司同事登录后可见；给客户看则免登录可见。

- 给同事：`login`，公司账号登录后可见。
- 给客户：`open`，免登录访问。
- 另有密码要求：按 html-gallery 的 `public` + password 规则处理；密码保护不是公司账号登录限制。
- 默认推荐同事，但未回复、预选值、旧报告设置都不能视为本次确认。
- 本次受众确认已经回答且范围未变，不重复追问；敏感内容确认可与受众问题合并。
- 更新也要确认此次受众，说明已知的旧访问范围，沿用原 slug 后按确认调整权限。

确认是否要发给客户不等于确认发布实名客户、内部数据、架构等敏感信息。指出具体类别、服务与受众，取得针对性确认或脱敏；密钥/令牌先移除。

## 上传范围与顺序

1. 仅准备最终 HTML 和必要资源的干净发布目录；单文件报告可直接上传该文件。
2. 不上传 `dataset.json`、原始响应、判定调整文件、配置、测试用例 fixture、源代码仓库、用户截图或浏览器记录。
3. 使用已安装技能完成登录检查与发布；只把鉴权发给该技能确认的目标服务。
4. 成功后返回部署脚本给出的 URL，记录本次 slug、受众和链接；不把密码/令牌写入记录。
5. 失败或超时明确状态，不捏造成功链接；不为测试安装而上传真实页面。

生成报告、公开发布、修改测试中心后台是三个不同授权范围。本技能默认只做前两者中用户本次要求的部分，绝不顺带改后台。分享此技能到 GitHub 不等于发布任何客户报告。
